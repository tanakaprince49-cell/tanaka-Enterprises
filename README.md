# Tanaka Enterprises

The software holding company of **Tanaka Gaadzikwa** — founder and CEO of LINKUP, based in Harare, Zimbabwe.

Live: https://tanaka-enterprises.vercel.app

---

## Stack

| | |
| --- | --- |
| Framework | React 19 + TypeScript |
| Build | Vite 6 |
| Styling | Tailwind CSS v4 (`@tailwindcss/vite`) plus a hand-written liquid-glass layer in `styles.css` |
| Routing | react-router-dom v7, real paths (no hash routing) |
| Icons | lucide-react |
| Deploy | Vercel (`vercel.json` supplied) |

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # vite build + prerender
npm run lint     # tsc --noEmit
```

No environment variables are required. The one outbound integration is the
Formspree endpoint used by the journal and contact forms.

## The design system

The glass is four layers, not just `backdrop-filter`:

1. **Aurora** — three slow-drifting colour blobs behind everything. Blur needs
   something colourful underneath or it reads as flat grey mud.
2. **Glass** — `backdrop-filter: blur() saturate(180%)` with a two-tone inset
   box-shadow that fakes the rim light of a real pane.
3. **Sheen** — a pointer-tracked highlight on the border and inside the surface
   (`--sheen-x` / `--sheen-y`, written by `GlassCard`).
4. **Grain** — an animated SVG turbulence film at 16% overlay, which is what
   stops the blur looking like plastic.

Motion is spring-eased and every animation is disabled under
`prefers-reduced-motion: reduce`. Cards reveal on scroll via a single
`IntersectionObserver` per element that disconnects after firing.

### Accessibility & low-end devices

- `backdrop-filter` is unsupported on a lot of budget Android — the class this
  site is most likely to be read on. `.glass--solid` and an `@supports` fallback
  give every surface a readable opaque tint instead.
- The mobile menu is a **fixed** overlay with a scrim, deliberately not nested
  inside the `<nav>`: a `backdrop-filter` cannot blur content inside its own
  stacking context, which made the first version transparent.
- Visible focus rings, labelled inputs, `aria-expanded` on the menu, real
  `alt` text on all 18 photos.

## SEO

Every route is **prerendered into static HTML at build time** — title,
description, canonical, OG/Twitter tags, a schema.org `@graph` and real
readable body copy with internal links. Crawlers that do not run JavaScript
still see a complete page. React replaces it for humans.

Generated by `scripts/prerender.mjs`:

| File | Contents |
| --- | --- |
| `dist/<route>/index.html` | one prerendered page per route |
| `dist/sitemap.xml` | 6 routes + inline image entries |
| `dist/sitemap-images.xml` | 18 press photos with title + caption |
| `dist/robots.txt` | allow-all + both sitemaps |

The entity graph links `Organization` → `Person` → `SoftwareApplication`
(LINKUP), all with stable `@id`s, so Google can resolve Tanaka Enterprises,
Tanaka Gaadzikwa and LINKUP as one connected set rather than three strangers.

### ⚠️ Change the domain before going live

`data/siteConfig.js` → `SITE.origin` currently points at the Vercel URL
because **`tanakaenterprises.com` is not owned by you** — it resolves to an
unrelated US company. Point it at whatever real domain you use and rebuild;
every canonical, OG tag, sitemap entry and JSON-LD id follows automatically.

## What was removed, and why

The previous version of this site was built around a product called **Nestly**,
and it had drifted a long way from reality:

| Removed | Reason |
| --- | --- |
| Nestly as the flagship product | It has no live app. `nestly-eight.vercel.app` returns **404**, and the entire site funnelled its CTAs ("Start Tracking Today", "Create Your Account") to it. |
| `/auth` and `/dashboard` | A fake login that accepted **any email address** and then showed a dashboard with a name/password editor that did nothing. Removed rather than fixed — there is no backend, and a broken login on a company site is worse than no login. |
| `tanaka@tanakaenterprises.com` | That domain is not yours. |
| `linkedin.com/in/tanaka-gaadzikwa-a7bb1335b` | Wrong profile. Correct one is `tanaka-gaadzikwa-linkup`. |
| "Global / Remote" | The company is in Harare. |
| "Strategic Partnerships & Investment" banner | Placeholder copy with no backing. Replaced with a real, current snapshot. |
| Stock Unsplash blog posts | Three placeholder articles, "Spring 2025" dates, "Coming Soon" labels. Replaced with four real entries. |
| Tailwind CDN script | In production builds, and blocked by most CSPs. Now compiled. |
| Unused deps | `@supabase/supabase-js` and `@google/genai` were installed but never imported. |

**Kept and fixed:** the light/dark toggle, the Formspree forms, the calm
monochrome aesthetic, and the brand line "building software that breathes"
(now the tagline *Software built with intent*).

## Known limits

- **Forms** post to Formspree with no local fallback; if the endpoint is down
  the UI still reports success. Acceptable for a lead form, not for anything
  transactional.
- **No analytics.** Vercel Analytics can be added — it is cookie-free — but it
  is deliberately not here by default.
- **The journal is static.** Entries live in `data/journal.js`. Move them to a
  CMS or Firestore before they need to be published often.
